# Heart Ledger Secure

Implement a blockchain-inspired ledger for biological signals (heart rate, sleep cycles). Ensure privacy guarantees with zero-knowledge proofs. Demonstrate storing, querying, and anonymizing health data securely.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://heart-cloak-chain.lovable.app
